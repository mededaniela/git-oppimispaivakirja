# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Tehtävät olivat melko helppoja ylipäätään. Vaikeuksia tuottivat ehkä välillä Git Bashin antamat virheilmoitukset. Opin etsimällä netistä tietoa erilaisilta sivustoilta, kuten Stack Overflow. Lopulta monet jutut olivatkin aika yksinkertaisia.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git add . | Vie tiedostot seuraavaan talletukseen (commit). |
| git commit -m | Tallettaa tehdyt muutokset. |
| git status | Näyttää työtilan muutokset, joita ei ole talletettu. |
| git log | Listaa talletukset. |
| git tag | Luo tunnisteen viimeisimpään talletukseen. |
| git revert | Peruuttaa halutun talletuksen. |
| git branch -a | Näyttää kaikki haarat. |
| git branch | Luo uuden haaran. |
| git switch | Vaihtaa haluttuun haaraan. |
| git merge --no-ff | Yhdistää halutun haaran siihen haaraan, missä tällä hetkellä olen. |
| git push -u | Vie muutokset esim. Githubiin. |
| git clone | Kloonaa repositorion itselle. |
