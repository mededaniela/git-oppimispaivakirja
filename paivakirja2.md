# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Osion tehtävä ei ollut juuri vaikea, mutta eri haarojen välillä liikkuminen oli hieman epämiellyttävää. Minua auttoi oppimaan se, että edellisten tehtävien tapaan etsin tietoa netistä. En ole kuitenkaan ihan varma, teinkö kaikki oikeassa järjestyksessä.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git branch new-feat | Loi uuden haaran. |
| touch feat.html | Loi uuden tiedoston haaraan. |
| git status | Tarkisti tallentamattomat muutokset. |
| git add . | Lisäsi muutokset seuraavaan talletukseen. |
| git commit -m | Talletti muutokset. |
| git push -u | Vei muutokset Githubiin. |
| git branch -d tyylit | Huomasin, etten ollut poistanut tätä haaraa. |
| git push -u origin new-feat | Vei uuden haaran Githubiin. |
| git switch | Vaihtelin haarojen välillä. |
| git fetch | Toi tiedostot etärepositoriosta. |
| git pull | Toi kaikki muutokset paikallisrepositorioon ja yhdisti ne. |
| git merge | Yhdisti new-feat -haaran main -haaraan. |
| git push -u origin tag | Vei uuden tunnisteen Githubiin. |
